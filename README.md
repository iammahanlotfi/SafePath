# SafePath AI

پروژه خام SafePath با Next.js و JavaScript.

## وابستگی‌های فعلی

فقط وابستگی‌های پایه اجرای Next.js نصب‌پذیر هستند:

- next
- react
- react-dom

در این نسخه هیچ کتابخانه جانبی برای نقشه، آیکون، استایل، درخواست HTTP یا اعلان نصب نشده است.
از Fetch API داخلی JavaScript برای درخواست‌ها استفاده خواهد شد.

## راه‌اندازی

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## نکته توسعه

کتابخانه‌های موردنیاز، مانند ابزار نقشه، فقط زمانی و پس از تصمیم‌گیری در فاز مربوطه اضافه خواهند شد.
منطق اصلی الگوریتم A* باید توسط دانشجو پیاده‌سازی شود.
