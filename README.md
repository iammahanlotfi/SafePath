# نقشه راه پیاده‌سازی پروژه SafePath AI

## فاز ۱: راه‌اندازی پروژه و طراحی رابط کاربری
- ایجاد پروژه با Next.js و JavaScript
- طراحی ساختار پوشه‌ها و فایل‌ها متناسب با نیاز پروژه
- طراحی Layout اصلی، هدر، سایدبار و صفحات
- طراحی صفحه اصلی و محیط نقشه
- طراحی پنل تنظیمات مسیریابی و اطلاعات پناهگاه‌ها
- استفاده از CSS Modules مشابه پروژه قبلی

**مسئولیت:** توسعه با کمک هوش مصنوعی و نظارت شخصی

## فاز ۲: پیاده‌سازی نقشه و آماده‌سازی داده‌های جغرافیایی
- اتصال نقشه با Leaflet و OpenStreetMap
- انتخاب موقعیت فعلی کاربر روی نقشه
- دریافت اطلاعات خیابان‌ها و تقاطع‌ها
- تبدیل اطلاعات جغرافیایی به گراف
- تعریف پناهگاه‌های آزمایشی و مختصات آن‌ها
- آماده‌سازی اطلاعات مسیرها برای ورود به الگوریتم

**مسئولیت:** توسعه با کمک هوش مصنوعی و نظارت شخصی

## فاز ۳: یادگیری و پیاده‌سازی الگوریتم A*
- یادگیری ساختار و منطق الگوریتم A*
- پیاده‌سازی Open Set و Closed Set
- پیاده‌سازی توابع g(n)، h(n) و f(n)
- بررسی و گسترش همسایه‌های هر گره
- انتخاب گره بعدی برای بررسی
- بازسازی مسیر نهایی
- تست الگوریتم روی گراف‌های کوچک و بررسی صحت نتایج

**مسئولیت:** پیاده‌سازی کامل الگوریتم توسط خودم؛ هوش مصنوعی صرفاً نقش آموزش و بررسی کد را دارد.

## فاز ۴: اتصال الگوریتم به اپلیکیشن
- اتصال الگوریتم A* به ساختار گراف پروژه
- دریافت مبدأ و مقصد
- بررسی پناهگاه‌های قابل دسترس
- اجرای الگوریتم برای پیدا کردن مسیر
- دریافت نتیجه و نمایش مسیر روی نقشه
- نمایش مسافت و زمان تخمینی رسیدن

**مسئولیت:** اتصال و توسعه با کمک هوش مصنوعی؛ منطق اصلی الگوریتم بدون جایگزینی یا بازنویسی توسط AI

## فاز ۵: پیاده‌سازی قابلیت‌های تکمیلی
- مدیریت مسیرهای مسدود و محدودشده
- بررسی ظرفیت خالی هر پناهگاه
- مسیریابی متناسب با شرایط کاربر (پیاده، خودرو و ویلچر)
- تخمین زمان رسیدن به پناهگاه
- درنظرگرفتن میزان ازدحام مسیرها
- محاسبه مجدد مسیر در صورت تغییر شرایط

**مسئولیت:** توسعه با کمک هوش مصنوعی و نظارت شخصی؛ تغییرات لازم در منطق الگوریتم با مشارکت و درک کامل خودم

## فاز ۶: نمایش مراحل الگوریتم و آمار جست‌وجو
- نمایش گره‌های بررسی‌شده
- نمایش گره‌های در صف بررسی
- نمایش مسیر نهایی پیدا‌شده
- نمایش تعداد گره‌های بررسی‌شده
- نمایش هزینه نهایی مسیر
- نمایش روند اجرای الگوریتم به‌صورت مرحله‌به‌مرحله

**مسئولیت:** توسعه رابط نمایشی با کمک هوش مصنوعی و ثبت اطلاعات اجرای الگوریتم توسط خودم

## فاز ۷: تست، رفع اشکال و آماده‌سازی ارائه
- تست مسیرهای عادی
- تست مسیرهای مسدود
- تست پناهگاه‌های تکمیل ظرفیت
- تست شرایط مختلف کاربران
- بررسی صحت مسیرهای محاسبه‌شده
- بررسی عملکرد الگوریتم A*
- آماده‌سازی مستندات فنی پروژه
- آماده‌سازی سناریوهای نمایشی و ارائه دانشگاهی

**مسئولیت:** مشترک؛ با حفظ مالکیت و تسلط شخصی بر الگوریتم اصلی

## تکنولوژی‌های اصلی پروژه

- Frontend: Next.js
- Language: JavaScript
- Styling: CSS Modules
- Map: Leaflet
- Map Data: OpenStreetMap
- Backend: Next.js Route Handlers
- API Requests: Fetch API
- AI Algorithm: A* (پیاده‌سازی شخصی)
- Database: در نسخه اولیه ضروری نیست

## اصول معماری و توسعه

1. معماری پروژه با الهام از سبک سازمان‌دهی پروژه قبلی Marketplace طراحی می‌شود، نه کپی کامل ساختار آن.
2. پوشه‌ها و فایل‌ها بر اساس نیاز واقعی SafePath ایجاد می‌شوند.
3. از Axios استفاده نمی‌شود و ارتباطات API با Fetch انجام می‌شود.
4. الگوریتم A* مستقل از رابط کاربری، API و سایر بخش‌ها پیاده‌سازی می‌شود.
5. کد اصلی الگوریتم توسط خودم نوشته می‌شود و هوش مصنوعی جایگزین آن نخواهد شد.
6. توسعه پروژه به‌صورت مرحله‌ای انجام می‌شود و پیش از ورود به فاز بعدی، صحت فاز قبلی بررسی خواهد شد.
7. اطلاعات پناهگاه‌ها و شرایط بحران در نسخه دانشگاهی آزمایشی هستند و خروجی پروژه برای هدایت اضطراری واقعی اعتبارسنجی نشده است.
